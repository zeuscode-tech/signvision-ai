# SignBridge — материалы для хакатона

## Одной фразой

SignBridge превращает ноутбук с веб-камерой в локального AI-помощника для общения: глухой человек показывает отдельные жесты русского жестового языка, система распознаёт и предлагает слова, а после подтверждения озвучивает их. Сотрудник отвечает кнопками крупным текстом. Всё работает офлайн — видео не покидает устройство.

## Проблема

Глухим и слабослышащим людям в больнице, банке, аптеке или МФЦ часто не к кому обратиться: сурдопереводчика рядом обычно нет, а записки на бумаге медленные и неудобные. Облачные решения не подходят там, где разговор конфиденциален (медицина, финансы).

## Решение

1. **Камера → слово.** Модель Easy Sign S3D (1598 изолированных жестов РЖЯ) распознаёт жест локально, через ONNX Runtime.
2. **Честная уверенность.** Шкала уверенности видна всегда. Ниже порога система говорит «Не понял, повторите», а не угадывает.
3. **Слово → фраза.** Человек подтверждает слово (Пробел) или выбирает похожее из Top-3; слова собираются во фразу.
4. **Фраза → голос.** Озвучка голосом macOS, без интернета.
5. **Ответ собеседника.** Экран оператора: огромный текст фразы, быстрые ответы из отраслевого словаря («Где у вас болит?»), свой ответ. Можно вывести на второй монитор или перевернуть экран.
6. **Имена — по буквам.** Если слова нет в словаре, переключение на дактильную азбуку (модель Bukva, 33 буквы).
7. **Свои жесты.** Студия: жест-имя или домашнее слово записывается за 10 повторов и обучается за секунды, прямо на ноутбуке.

## Что уже работает (MVP)

- Распознавание с камеры в реальном времени через WebSocket: кадры → модель → слово с уверенностью и Top-3.
- Отраслевой словарь «Медицина» ограничивает распознавание словами сценария — так точнее.
- Защита от повторов: удерживаемый жест засчитывается один раз; пауза — опущенные руки.
- Экран собеседника, второе окно, быстрые ответы.
- Дактильный алфавит, практика, прогресс с интервальным повторением.
- Студия собственных жестов с честной проверкой на независимых повторах.
- Экспорт, импорт и удаление данных; приватность по умолчанию.
- 117 автотестов backend, линтеры и проверка типов; для длительной проверки предусмотрен отдельный soak-тест.

## Технологии

FastAPI, WebSocket, ONNX Runtime, MediaPipe, OpenCV, scikit-learn, SQLite + Alembic · React + TypeScript + Vite · всё локально на Mac (Apple Silicon).

## Честные ограничения

- Это не переводчик свободной жестовой речи: распознаются отдельные жесты с паузами.
- Точность зависит от света, ракурса и похожести на обучающий датасет; цифры точности на вашей камере мы не заявляем без замеров.
- Шаблоны фраз и учебные материалы РЖЯ добавляются только после проверки экспертом.

## Сценарий демо-видео (≈2 минуты)

1. **0:00–0:10.** Лендинг: «Говорите руками — вас поймут». Кадр с индикатором «Без интернета».
2. **0:10–0:25.** Главная → «Начать разговор». Камера, точки на руках, светящийся след пальца.
3. **0:25–0:55.** Покажите 2–3 слова из словаря «Медицина» (например «врач», «болеть», «голова»). Каждое слово появляется со шкалой уверенности, Пробел — во фразу.
4. **0:55–1:05.** Покажите непонятный жест — экран «Не понял. Повторите жест чуть медленнее». Подчеркните: система не угадывает.
5. **1:05–1:15.** «Озвучить» — фраза звучит вслух.
6. **1:15–1:35.** «Показать собеседнику»: огромный текст, оператор нажимает «Где у вас болит?» — ответ крупно на весь экран.
7. **1:35–1:50.** «По буквам»: имя дактилем.
8. **1:50–2:00.** Настройки → «Видео не сохраняется и не отправляется». Финальный кадр с логотипом.

Советы для записи: ровный свет спереди, однотонный фон, руки целиком в кадре, жест 1–2 секунды и короткая пауза (опустить руки).

## Запуск для жюри

```bash
git clone https://github.com/zeuscode-tech/signvision-ai.git
cd signvision-ai
./setup.sh   # один раз: зависимости и модели (нужен интернет)
./start.sh   # дальше работает без интернета
```

Откройте <http://127.0.0.1:5173> в Chrome или Safari и разрешите доступ к камере. Лендинг — `site/index.html` (статическая страница).
