# SignVision AI

Локальный AI-тренажёр жестов для macOS Apple Silicon. Камера и MediaPipe работают в браузере, backend хранит только landmarks, локальную модель и прогресс. Облачные API не используются.

> Важно: приложение **не содержит выдуманных соответствий РЖЯ**, не подменяет преподавателя и не переводит свободную жестовую речь. Учебные разделы РЖЯ, для которых нет проверенного лицензированного материала, честно отмечены как требующие наполнения. Рабочий словарь создаёт пользователь в AI Training Studio.

## Что реализовано

- MediaPipe Hand Landmarker: до двух рук, 21 точка на руку, скелет, зеркальный preview, фактические FPS и latency.
- Готовая динамическая ONNX-модель Bukva: 33 буквы РЖЯ + `no_event`, без первоначального пользовательского обучения.
- Нормализация относительно запястья и масштаба кисти; фиксированный вектор Left + Right.
- Реальный Random Forest classifier, вероятности, порог отказа и стабилизация по нескольким кадрам.
- Capture sessions, отрицательный класс, удаление классов/образцов через API.
- Session-level train/test split без смешивания кадров одной записи; precision, recall, F1 и confusion matrix в API, когда данных достаточно.
- Learn, Practice, Quiz, Free Recognition, AI Training Studio, Progress и Settings.
- SQLite: попытки, успехи, время, дневная активность, адаптированный SM-2.
- Экспорт/импорт прогресса и полное локальное удаление данных.
- Светлая/тёмная темы, адаптивный интерфейс, состояния камеры/модели/пустых данных.
- Автоматические тесты backend и typecheck/build frontend.

## Установка

Требуются macOS, Homebrew, Node.js 20+ и Python 3.11. На Apple Silicon стандартный путь Python — `/opt/homebrew/bin/python3.11`.

```bash
cd signvision-ai
chmod +x setup.sh start.sh
./setup.sh
```

`setup.sh` один раз устанавливает зависимости, копирует WASM MediaPipe и скачивает официальные модели Hand Landmarker и Bukva. После этого работа приложения не требует интернета.

Если Python расположен иначе:

```bash
PYTHON_BIN=/путь/к/python3.11 ./setup.sh
```

## Запуск

```bash
./start.sh
```

Откройте <http://127.0.0.1:5173>. Сервер слушает только `127.0.0.1`. API-документация: <http://127.0.0.1:8000/docs>.

При первом включении камеры браузер спросит разрешение. В macOS его можно изменить в **System Settings → Privacy & Security → Camera**.

## Первый рабочий словарь

1. Откройте **AI Studio**.
2. Создайте минимум один целевой класс. Используйте нейтральное имя, пока правильность жеста РЖЯ не проверена по авторитетному источнику.
3. Создайте класс `неизвестно`, включив отрицательный флажок.
4. Для каждого класса создайте минимум две независимые сессии и соберите по 20–30 кадров.
5. Не держите руку совершенно неподвижно: немного меняйте расстояние и угол. Между сессиями меняйте освещение/фон.
6. Нажмите **Обучить модель**. Если данных мало для честного test split, интерфейс прямо это сообщит.
7. Проверьте модель во **Free Recognition**, затем используйте Practice/Quiz.

Вероятность модели — не оценка анатомической точности. Приложение не придумывает советы по исправлению пальцев.

## Готовая модель алфавита

Откройте раздел **Алфавит** и включите камеру. Встроенная модель Bukva анализирует последовательности по 8 кадров и поддерживает статические и динамические буквы. Она уже скачана и лежит в `models/bukva_mobilenetv2_tsm.onnx`.

Инференс работает локально через ONNX Runtime. Кадры передаются только loopback-серверу `127.0.0.1`, не записываются в SQLite или файловую систему и не отправляются в интернет. При вероятности ниже 45% интерфейс показывает отказ от распознавания.

Атрибуция и лицензии: [docs/THIRD_PARTY_DATA.md](docs/THIRD_PARTY_DATA.md).

## Slovo landmarks (опционально)

Архив landmarks имеет размер около 1,2 ГБ. Для загрузки или продолжения прерванной загрузки с официального хранилища:

```bash
./scripts/download_slovo_landmarks.sh
```

Скрипт поддерживает продолжение прерванной загрузки, извлекает официальный `annotations.csv` без скачивания 16-гигабайтного видеоархива и проверяет точный размер landmarks. Посмотреть классы и импортировать выбранные статические жесты:

```bash
.venv/bin/python scripts/import_slovo_landmarks.py --list-classes
.venv/bin/python scripts/import_slovo_landmarks.py --classes "А,Б,В"
```

Импорт намеренно требует явного выбора: динамические слова нельзя честно превратить в независимые статические кадры. После импорта обучите пользовательскую модель в **AI Studio**.

## Данные и приватность

- В пользовательских статических режимах браузер извлекает landmarks; backend получает 126 чисел на кадр.
- В режиме **Алфавит** восемь уменьшенных JPEG-кадров передаются локальному backend на `127.0.0.1` для ONNX-инференса. Они не записываются на диск и не уходят в интернет.
- SQLite: `data/signvision.db`.
- Модель: `models/static_gestures.joblib`.
- Settings позволяет экспортировать/импортировать прогресс или удалить все пользовательские данные.

## Типичные проблемы

- **Модель Hand Landmarker не загружается:** повторите `./setup.sh`; файл `frontend/public/models/hand_landmarker.task` должен существовать.
- **Камера запрещена:** дайте разрешение браузеру в настройках macOS и перезагрузите страницу.
- **Модель всё угадывает одним классом:** соберите больше независимых сессий, обязательно добавьте разнообразный отрицательный класс.
- **Метрик нет:** нужно минимум две независимые capture sessions для каждого класса и достаточное число групп для split.
- **Низкий FPS:** закройте приложения, использующие камеру, уменьшите освещение заднего плана; смотрите фактические значения в overlay.
- **Порт занят:** завершите предыдущий `start.sh`; backend использует 8000, frontend — 5173.
- **Нужны другие порты:** `SIGNVISION_BACKEND_PORT=8010 SIGNVISION_FRONTEND_PORT=5180 ./start.sh`.

## Ограничения и дальнейшая работа

- Bukva распознаёт буквы РЖЯ, но не переводит слова, фразы или грамматику жестового языка.
- Готовая модель использует окно из восьми кадров; качество зависит от освещения, ракурса и сходства камеры с исходным датасетом. Порог 45% — локальное правило отказа, а не опубликованная авторами калибровка.
- Импорт Slovo предназначен только для явно выбранных статических классов. Для динамических слов нужен отдельный последовательностный пайплайн с корректными границами жеста.
- Анализ лица, корпуса и грамматики РЖЯ пока не реализован; архитектура камеры может быть расширена до Holistic landmarks.
- Confusion matrix возвращается API в отчёте обучения; UI показывает per-class precision/recall/F1. Полная матрица доступна через `/api/model`.
- Качество зависит от пользовательского датасета. Приложение не делает заявлений о точности без независимой проверки.
